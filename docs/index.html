Machine Learning Foundations & Viva Defense Guide

Comprehensive conceptual derivations prepared for the ES 335 Machine Learning examination.

1. Dual Task Formulation: Return Regression vs Tail Risk Classification

+

In standard financial econometric literature, risk is often framed as parametric volatility (\(\sigma\)). In our Machine Learning framework, we formulate market risk directly through two supervised machine learning tasks on a 1-Day Horizon:

  • Task A (Supervised Regression): Predict the next-day logarithmic return \(y_{\text{reg}, t} = r_{t+1} = \ln(P_{t+1} / P_t) \times 100\). Loss function: Mean Squared Error \(L_{\text{MSE}} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2\).
  • Task B (Supervised Tail Classification): Predict whether the next-day return falls into the catastrophic tail crash region \(y_{\text{cls}, t} = \mathbb{I}(r_{t+1} \le -1.60\%)\) (historical 5th percentile). Loss function: Binary Cross-Entropy with balanced class weighting.

2. Linear Regression with L2 Regularization (Ridge Regression)

+

Ordinary Least Squares (OLS) minimizes the residual sum of squares: \(\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2\). When features exhibit strong multicollinearity (such as \(\sigma_{5d}\), \(\sigma_{20d}\), and \(\sigma_{60d}\)), \((\mathbf{X}^T\mathbf{X})\) becomes ill-conditioned with eigenvalues close to zero, causing extreme coefficient variance.

Ridge Regression adds an \(L_2\) penalty on weight magnitudes:

$$\mathcal{L}_{\text{Ridge}}(\mathbf{w}) = \frac{1}{2N} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \frac{\alpha}{2} \|\mathbf{w}\|_2^2 \implies \mathbf{w}^* = (\mathbf{X}^T\mathbf{X} + \alpha \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y}$$

3. Non-Parametric Recursive Partitioning: Decision Trees (CART)

+

Classification and Regression Trees (CART) partition the feature space into hyper-rectangles \(R_m\). At each node, the algorithm greedily searches for the optimal feature \(j\) and split point \(s\) that maximizes impurity reduction:

For Regression: Splitting minimizes total variance (Mean Squared Error):

$$\min_{j, s} \left[ \sum_{i \in R_1(j, s)} (y_i - \bar{y}_{R_1})^2 + \sum_{i \in R_2(j, s)} (y_i - \bar{y}_{R_2})^2 \right]$$

For Classification: Splitting minimizes Gini Impurity \(I_G(p) = 1 - \sum_{k=0}^1 p_k^2\).

4. Kernel Margin Optimization: Support Vector Machines (SVR & SVC)

+

Support Vector Machines map feature vectors into a reproducing kernel Hilbert space (RKHS) via the non-linear Gaussian Radial Basis Function (RBF) kernel:

$$K(\mathbf{x}, \mathbf{x}') = \exp\left(-\gamma \|\mathbf{x} - \mathbf{x}'\|^2\right)$$

Errors smaller than Vapnik's \(\varepsilon\)-insensitive threshold incur zero loss, giving SVR exceptional robustness against daily market noise.

5. Probabilistic Classification: Logistic Regression with Balanced Loss

+

Logistic Regression models the posterior probability of a high-risk tail event via the standard logistic sigmoid link function:

$$P(y = 1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x} + b)}}$$

We handle the 95:5 class imbalance by applying inverse-frequency sample weights \(w_k = \frac{N}{2 N_k}\) (\(\approx 19:1\)), heavily penalizing missed tail crashes.
